A **request class** is a group of related requests. For an audit, classes are usually financial-statement lines — *Cash and cash equivalents*, *Accounts receivable*, *Revenue*. For tax or advisory work they are whatever grouping suits (for example *VAT Filing*, *PAYE*).

Every request type belongs to a class, so every request does too. An engagement can only have requests in classes that are **in scope** for it.

## Adding and removing classes

On the **Settings** tab, under **Request classes** (Super Admins and the Lead):

- **Add** — search for an existing class, or type a new name to create one. It is added to the engagement straight away.
- **Remove** (the bin) — the requests are **not** deleted, but they are no longer grouped under that class.

You can also choose classes when you [create the engagement](help:creating-an-engagement).

## Progress by class

On the **Requests** tab, the **Classes** list shows each class with its progress — for example *0% · 0/3 done · 1 overdue*. Click a class to see only its requests, or **All classes** for everything.

## Signing off a class

When the work on a class is finished, sign it off: on the Settings tab, click **Sign off** next to the class, add an optional note, and confirm. The class shows **Signed off**. See [Stages and sign-off](help:engagement-stages-and-sign-off).
